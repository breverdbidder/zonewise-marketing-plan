# 04 — Conversion Triggers: Paywall Placement & Psychology

## Core Principle

Every paywall is placed at the **moment of maximum desire** — when the user WANTS something specific, not when we want to show them a feature list.

---

## Paywall Design Principles

### 1. Show, Don't Tell
Never describe a feature abstractly. Always show the specific value they're missing ON the specific property they're looking at.

**Bad:** "Upgrade for ML predictions"
**Good:** "This property scored 78/100. Our AI recommends BID. Upgrade to see the full analysis."

### 2. Quantify the Loss
**Bad:** "You're missing out on insights"
**Good:** "Last month, PRO users in [County] identified $2.3M in equity opportunities across 7 BID-rated properties"

### 3. Create Time Pressure
**Bad:** "Upgrade anytime"
**Good:** "This auction is in 3 days. 23 PRO users have already analyzed this property."

### 4. Social Proof at Point of Decision
Every paywall includes one of:
- "[X] PRO users analyzed this property today"
- "[X] investors in [County] use ZoneWise PRO"
- "PRO users found [X] BID opportunities last month"

### 5. Easy Escape, Easy Return
Always provide a "Not now" or "Continue with Free" option. Never trap users. The paywall will come back — every locked feature is another chance.

## Behavioral Upgrade Triggers (Non-Paywall)

These fire based on user behavior, not feature clicks:

### High-Engagement Free User
**Trigger:** Free user logs in 5+ days in a row
**Action:** In-app banner: "You're a power user on the Free plan. Imagine what you could do with PRO. First month 20% off."

### Auction Eve
**Trigger:** Free user viewed properties for an auction happening tomorrow
**Action:** Push notification: "Tomorrow's auction: [X] properties. PRO users have full analysis. You're going in blind. [Upgrade Now]"

### Post-Auction Regret
**Trigger:** Auction results published, free user had viewed properties
**Action:** Email: "Yesterday's auction results are in. [Property] sold for $X. Our ML predicted [outcome]. See how you could have known. [Upgrade to PRO]"

### Competitor Awareness
**Trigger:** Free user views a property that many PRO users are also viewing
**Action:** Badge on property: "🔥 High Activity — 15 PRO users analyzing this property"

## B2B-Specific Conversion Triggers

### Volume Threshold
**Trigger:** B2B trial user processes 20+ properties
**Action:** "Your team has analyzed 20 properties. At this volume, you need Enterprise. [Schedule a Call]"

### Multi-User Detection
**Trigger:** Multiple logins from same company domain
**Action:** "Multiple people at [Company] are using ZoneWise. Enterprise seats are more cost-effective. [Learn More]"

### White-Label Report Request
**Trigger:** B2B user tries to generate a report without their branding
**Action:** "Enterprise users get white-label reports with your company logo. [Upgrade to Enterprise]"
